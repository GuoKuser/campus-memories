# 校园回忆相册

一个可直接部署到 GitHub Pages 的静态图片/视频相册。零依赖、无需构建。

## 本地预览

直接打开 `index.html`，或在本目录启动任意静态文件服务器。

## 部署

将整个目录推送到 GitHub 仓库，在 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。

## 素材

页面使用 `assets/` 中的 27 张照片和 4 段视频。原始文件被统一重命名，以避免 GitHub Pages 路径编码问题。

## 参考

交互与单文件结构参考 MIT 许可项目 [Vojislav77/gallery-website](https://github.com/Vojislav77/gallery-website)，并针对中文校园回忆主题重新设计、加入视频支持。
